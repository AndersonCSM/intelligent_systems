# Project Robotics - Índice do Projeto

Este arquivo tem o objetivo de servir como um índice (mapa) atualizado do repositório, para que assistentes e agentes IA possam entender a estrutura rapidamente sem precisar reler ou buscar os arquivos frequentemente.

## 📂 Estrutura de Diretórios

### `/` (Raiz)
- **`README.md`**: Arquivo principal com informações sobre o projeto, setup e exemplos de uso do robô e-puck no Webots.
- **`PROJECT_INDEX.md`**: Este arquivo. Um mapa da estrutura de diretórios e arquivos do projeto.
- **`.gitignore`**: Arquivos e pastas ignorados no versionamento (ex: `__pycache__`, `robotics/`).
- **`skills/`**: Pasta reservada para armazenar "skills" (scripts, prompts ou pequenas rotinas especializadas) para agentes IA ou funcionalidades modulares do projeto.

### `/controllers/controller_project/`
Pasta contendo o controlador principal do robô no Webots e scripts de aprendizado por reforço (Gymnasium).
- **`robot.py`**: Definição da classe principal e integração direta com o Webots (possível evolução ou substituto do `locomotion.py` original).
- **`controller_project.py`**: Controlador utilizado diretamente pelo Webots, referenciado na interface do simulador.
- **`robot_env.py`**: Ambiente do tipo `gym.Env` configurado para o treinamento de aprendizado por reforço.
- **`rewards.py`**: Funções matemáticas de recompensa para o RL (incentiva movimento, penaliza colisões).
- **`train.py`**: Script de treinamento usando o ambiente do Gymnasium.
- **`test_model.py`**: Script de inferência/teste do modelo treinado.
- **`examples.py`**: Códigos com exemplos práticos de uso.
- **`config.yaml`**: Parâmetros de hiper-configuração e ambiente (passos, sensores, velocidade max, etc).
- **`runtime.ini`**: Configuração runtime do controlador Webots.

### `/docs/`
- **`SETUP_RESUMO.md`**: Guia em formato de resumo rápido para setup no sistema.
- **`requirements.txt`**: Todas as dependências pip do Python para a execução do projeto.

### `/scripts/`
- **`setup_venv.sh`**: Script bash para automatizar a criação do virtual environment e a instalação das dependências.

### `/worlds/`
- **`mundo1.wbt`**: Arquivo de definição principal do mundo/cenário do Webots (que inclui a arena, os obstáculos e o nó do e-puck).
- **`.mundo1.wbproj` / `.mundo1.jpg`**: Arquivos auxiliares e miniaturas geradas pelo simulador Webots.

### `/robotics/`
- Pasta gerada do Virtual Environment do Python (`venv`). Não deve ser versionada nem modificada manualmente.
