# intelligent_systems
Repository for content in intelligent systems

Repository for the Intelligent Systems course.

## Project Structure

The repository is divided into two main projects and an agent configuration directory:

```text
.
├── README.md
├── LICENSE
├── course/                  # Course materials, assignments, and notebooks
│   ├── environment.md
│   ├── workflow.md
│   ├── guide.md
│   ├── requirements.txt
│   ├── unidade_1/           # Foundations, Regressions, kNN, Perceptron, Adaline
│   ├── unidade_2/           # MLP Networks, CNNs, Decision Trees
│   ├── unidade_3/
│   └── projects/            # Applied machine learning projects
│       ├── Intrusion_detection_system_using_MLP.ipynb
│       ├── Ionosphere-Detection-adaline-neural-network.ipynb
│       ├── heart_disease_logistic_regression.ipynb
│       ├── power_plant_linear_regression.ipynb
│       └── wine_classification_using_knn.ipynb
└── project-robotics/        # Applied robotics project (Webots + RL)
    ├── controllers/
    │   └── robot_v4.py/     # Main Python controllers for Webots (robot.py, etc.)
    ├── worlds/              # Webots simulation worlds (e.g., mundo1.wbt)
    ├── docs/                # Robotics-specific documentation
    └── README.md
```

## Course Plan

- **Institution:** UFERSA - Pau dos Ferros Campus - DETEC;
- **Instructor:** Pedro Thiago Valerio de Souza;
- **Original repository:** <https://github.com/pedrothiag/intelligent-systems>.
- **Current repository:** <https://github.com/AndersonCSM/intelligent_systems>.


### I. Objectives

- Introduce the concept of Artificial Intelligence;
- Present common AI approaches;
- Present elementary Machine Learning concepts;
- Understand regression concepts;
- Study the main existing neural network architectures;
- Understand problem solving using uninformed, heuristic, population-based, and stochastic search algorithms;
- Present AI methods based on trees.

### II. Syllabus

- Introduction to Artificial Intelligence;
- Data analysis and preprocessing;
- Machine Learning and training algorithms;
- Linear and logistic regression;
- k-Nearest Neighbors (k-NN);
- Support Vector Machines (SVM);
- Clustering algorithms;
- Introduction to Artificial Neural Networks;
- Perceptron and Adaline;
- Multilayer Perceptron (MLP);
- Convolutional Neural Networks (CNN);
- Decision trees;
- Naive Bayes classifier;
- Search methodologies (uninformed and informed search);
- Genetic algorithms;
- Simulated annealing;
- Deep Learning concepts;
- Natural Language Processing concepts;
- Applications in Artificial Intelligence.
